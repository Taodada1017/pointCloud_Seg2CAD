# 面向室内BIM重建的点云语义分割与CAD平面图自动生成

## 研究生毕业设计 · 技术路线与创新点介绍

---

## 一、研究背景与目标

### 1.1 研究背景

建筑信息模型（BIM）是建筑行业数字化转型的核心载体，但现有室内场景的BIM建模仍高度依赖人工测量与手动绘制，效率低下、成本高昂。随着激光雷达（LiDAR）技术的发展，通过点云数据自动生成建筑CAD平面图成为重要的研究方向。

然而，从原始LiDAR点云到规范化的CAD平面图，面临三个关键挑战：

1. **语义理解**：如何从点云及关联图像中识别墙体、地板、天花板、家具等语义类别
2. **2D-3D融合**：如何将多视角2D图像的语义分割结果准确映射到3D点云空间
3. **几何提取**：如何从语义化的点云中提取出规范的建筑结构线段

### 1.2 研究目标

设计并实现一套端到端的自动化管线：

```
LiDAR彩色点云 + 多视角图像 + 相机位姿
        ↓
    带真实尺度的2D CAD平面图（含DXF格式）
```

│                                                                 │

┌─────────────────────────────────────────────────────────────────┐
│              阶段二：3D语义实例融合（核心创新）                     │
│                                                                 │

│    ③ 3D点集级IoU数据关联（替代传统2D IoU）                        │

│  输出：带真实尺度的2D CAD平面图                                    │
└─────────────────────────────────────────────────────────────────┘

## 三、核心创新点

### 🔵 核心创新：基于3D点集级IoU的语义实例数据关联（阶段二）

**现有方法的不足**：

传统的多视角语义融合方法在进行2D检测结果与3D实例的数据关联时，通常在2D图像平面上计算IoU。这种方式受视角变化和遮挡影响严重——同一物体从不同角度拍摄时，2D mask可能完全不重叠，导致关联失败。

**本文方法**：

将数据关联从2D图像空间提升到3D点云空间。核心步骤：

1. **视锥体点云筛选**：基于体素哈希映射（VoxelHashMap），使用DDA（Digital Differential Analyzer）算法快速遍历相机视锥体穿过的体素格子，避免暴力遍历全局3500万点云。结合TBB多线程并行和凸包可见性检测，高效获取当前帧可见点集。

2. **2D→3D反投影**：对阶段一每个检测结果的mask区域，通过针孔相机模型将可见点的2D投影坐标与mask做匹配，获得每个2D检测对应的3D点集。

3. **3D点集级IoU关联**：

```
传统方法：  IoU_2D = |mask_A ∩ mask_B| / |mask_A ∪ mask_B|    （图像像素级）
本文方法：  IoU_3D = |points_A ∩ points_B| / |points_A ∪ points_B|  （3D点索引级）
```

同一物体从不同视角观测到的3D点集天然共享物理空间，IoU_3D对视角变化天然鲁棒。采用双向最大匹配策略（行/列方向一致才确认），对歧义对用3D IoU决定是否合并。

4. **贝叶斯多帧语义融合**：设计似然矩阵将RAM开放词汇标签映射到预定义建筑类别，多帧观测累积后验概率，比单帧投票更稳定。

**创新意义**：
- 关联准确率不受视角变化影响
- 体素哈希加速使得3D级关联的计算开销可控
- 贝叶斯融合利用多帧冗余信息提升语义分类鲁棒性

## 四、辅助创新点

### 🟢 辅助创新一：面向室内建筑的语义先验过滤（阶段一）

**动机**：RAM是通用图像标签模型，在室内建筑场景中会输出大量无关标签（如"tape"、"hallway"、"office building"），这些噪声标签传递给GroundingDINO后产生误检，影响下游融合质量。

**方法**：
- 构建室内建筑目标类别层级表：
  - 结构类：wall、floor、ceiling、pillar、beam、door、window、stair
  - 非结构类：chair、desk、table、sofa、cabinet、shelf
- 利用CLIP模型计算RAM输出标签与预定义类别的语义相似度
- 过滤语义相似度低于阈值的标签，仅保留与室内建筑相关的标签
- 同时为每个检测标注"结构/非结构"属性，传递给阶段二辅助实例分类

**预期效果**：减少误检，提升阶段二数据关联的准确率。

---

### 🟢 辅助创新二：基于视角覆盖的关键帧选取策略（阶段一）

**动机**：当前对全部145张图像逐帧运行RAM+DINO+SAM三个大模型级联（CPU上约2小时），存在大量冗余——相邻帧视角变化小，语义信息高度重复。

**方法**：
- 基于相机位姿计算相邻帧的视角变化量（旋转角度+平移距离）
- 设定视角变化阈值，低于阈值的帧标记为冗余帧
- 引入场景覆盖率约束，确保每个空间区域至少被N帧覆盖
- 最终从145帧中选取约30帧关键帧进行完整处理

**预期效果**：计算量降低约80%（145帧→30帧），同时保持分割质量。

---

### 🟢 辅助创新三：自适应点云投影参数估计（阶段三）

**动机**：点云投影到2D平面时需要指定水平切片的高度范围，但不同建筑、不同楼层的绝对高度完全不同，硬编码参数无法泛化。

**方法**：
- 对结构点云的Z轴建立直方图
- 自动检测地板（最低密集峰）和天花板（最高密集峰）的高度
- 切片范围自动设定为 [Z_floor + margin, Z_ceiling - margin]
- 同时去除Manhattan强制正交约束，保留所有方向的墙线

**实测效果**：在同一数据上，墙线检测从5条提升至79条，信息量提升15倍。
