## 一、输入数据规格（设备固定参数）

### 1.1 彩色点云 (colorized.pcd)

| 属性 | 值 |
|------|-----|
| 每点属性 | (x, y, z, r, g, b) |
| 坐标单位 | 米（m） |

### 1.2 多视角图像

| 属性 | 值 |
|------|-----|
| 分辨率 | 1600 × 1600 像素 |
| 格式 | JPEG |

### 1.3 相机位姿 (transforms.json)

每张图像对应一个4×4的变换矩阵（camera-to-world），描述相机在世界坐标系中的位置和朝向。

### 1.4 相机内参

```yaml
image_width: 1600
image_height: 1600
camera_fx: 785.17    # x方向焦距（像素）
camera_fy: 785.30    # y方向焦距（像素）
camera_cx: 800.00    # 主点x坐标
camera_cy: 800.00    # 主点y坐标
# 视场角 FOV ≈ 91°
```

## 二、阶段一：2D开放词汇语义分割

### 2.1 目标

对每张输入图像，自动识别图中所有物体，输出：
1. **像素级分割mask**：哪些像素属于该物体
2. **语义标签**：物体类别（如 "chair"、"floor"、"wall"）
3. **检测置信度**：模型对识别结果的确信程度

### 2.2 三模型级联流程 ✅ 已完成

```
输入图像 (1600×1600)
    │
    ▼
┌─────────────────────────────────────────────┐
│  RAM (Recognize Anything Model)              │
│  输入：图像（缩放到384×384）                   │
│  输出：文本标签列表                             │
│  作用：告诉后续模型"这张图里可能有什么"          │
└───────────────┬─────────────────────────────┘
                │
                ▼
┌─────────────────────────────────────────────┐
│  🔲【P0 待实现】语义先验过滤                    │
│  输入：RAM输出的文本标签                        │
│  输出：过滤后的室内建筑相关标签                  │
│  方法：CLIP语义相似度 > 阈值                    │
└───────────────┬─────────────────────────────┘
                │
                ▼
┌─────────────────────────────────────────────┐
│  GroundingDINO (开放集目标检测)        ✅     │
│  输入：图像 + 文本标签                         │
│  输出：检测框 (bounding box) + 置信度          │
└───────────────┬─────────────────────────────┘
                │
                ▼
┌─────────────────────────────────────────────┐
│  SAM (Segment Anything Model)         ✅     │
│  输入：图像 + 检测框（作为prompt）              │
│  输出：每个框对应的精确像素级mask               │
└─────────────────────────────────────────────┘
```

### 2.3 【P0 待实现】语义先验过滤

> **状态**：🔲 待实现 | **优先级**：P0 | **难度**：⭐⭐☆☆☆

**动机**：RAM是通用图像标签模型，会输出大量无关标签（如"tape"、"hallway"、"office building"），产生误检。

**实现思路**：
- 定义室内建筑相关的类别词表（structural 和 non_structural 两类）
- 使用CLIP模型计算RAM输出标签与预定义词表的语义相似度
- 保留相似度超过阈值的标签，过滤掉无关标签
- 同时记录每个标签属于"结构类"还是"非结构类"

**预期效果**：误检数减少约30-50%

---

### 2.4 【P0 待实现】关键帧选取策略

> **状态**：🔲 待实现 | **优先级**：P0 | **难度**：⭐⭐⭐☆☆

**动机**：当前对全部图像逐帧处理，相邻帧视角变化小，信息冗余，计算量大。

**实现思路**：
- 计算相邻帧之间的相对位姿变化（旋转角度 + 平移距离）
- 当旋转角度超过阈值（如15°）或平移距离超过阈值（如0.5m）时，选为关键帧
- 第一帧总是关键帧

**参数设置**：
| 参数 | 推荐值 | 说明 |
|------|--------|------|
| angle_threshold | 15° | 室内转角常见角度 |
| distance_threshold | 0.5m | 移动半米以上视角变化明显 |

**预期效果**：处理帧数减少约80%，精度损失 < 5%

### 2.5 阶段一输出格式 ✅ 已完成

**1. mask图像 (`*_mask.png`)**

与原图同尺寸的 uint16 灰度图（1600×1600），每个像素值代表实例ID：

```
值 = 0  →  背景
值 = 1  →  第1个检测物体
值 = 2  →  第2个检测物体
...
```

**2. 标签文件 (`*_label.json`)**

包含每个检测实例的：
- 实例ID
- 语义标签及置信度
- 检测框坐标

## 三、阶段二：3D语义实例融合（核心）

### 3.1 目标

将阶段一的 **2D语义mask** 融合到 **3D点云空间**，使每个点都被标注为某个**语义实例**，最终将非结构类实例从点云中移除。

### 3.2 核心挑战

1. **一个3D物体被多帧看到**：同一把椅子可能出现在多张照片中，需要确定它们是同一物体
2. **遮挡**：有些点在视野内但被遮挡，不应被标注
3. **语义不一致**：同一物体在不同帧被识别为不同标签（"carpet" vs "floor" vs "mat"）

### 3.3 整体流程 ✅ 已完成

```
初始化：加载点云 → 构建体素哈希索引
         ↓
对每一帧（位姿逐个遍历）：
    │
    ├─ Step 1: 视锥体点云筛选
    │    "当前相机能看到哪些3D点？"
    │
    ├─ Step 2: 2D mask → 3D点集映射
    │    "mask里的像素对应哪些3D点？"
    │
    ├─ Step 3: 3D点集级IoU数据关联 ⭐核心创新
    │    "这组3D点和已知的哪个实例是同一物体？"
    │
    └─ Step 4: 实例更新与语义融合
         匹配到 → 合并点集 + 更新标签
         未匹配 → 创建新实例
         ↓
后处理：合并碎片实例 → 分类 → 移除家具点
```

---

### 3.4 Step 1：视锥体点云筛选 ✅ 已完成

#### 3.4.1 数学原理：针孔相机投影

将3D点 **P_world = (X, Y, Z)** 投影到图像像素坐标 **(u, v)**：

**第一步：世界坐标 → 相机坐标**
```
P_cam = T_world_to_cam × P_world
```

**第二步：相机坐标 → 像素坐标**
```
u = fx × (X_cam / Z_cam) + cx
v = fy × (Y_cam / Z_cam) + cy
```

**可见性判断**：
- 0 ≤ u < 1600 且 0 ≤ v < 1600 → 在图像范围内
- Z_cam > 0 → 在相机前方

#### 3.4.2 体素哈希加速 ✅ 已完成

**问题**：暴力遍历全部点云，每帧计算量巨大。

**解决方案**：

1. **建立体素索引**：将3D空间划分为固定大小的体素格子

2. **哈希函数映射**：使用空间哈希函数将体素坐标映射到哈希表

3. **DDA视锥体遍历**：只遍历相机视锥体穿过的体素格子

**加速效果**：约 40倍

#### 3.4.3 可见性检测 ✅ 已完成

使用凸包算法剔除被遮挡的点。

---

### 3.5 Step 2：2D mask → 3D点集映射 ✅ 已完成

对当前帧的每个检测：
- 遍历所有可见点
- 将点投影到图像坐标
- 根据mask值判断该点属于哪个检测实例
- 构建每个检测的点索引集合

---

### 3.6 Step 3：3D点集级IoU数据关联 ⭐ 核心创新 ✅ 已完成

#### 3.6.1 传统方法（2D IoU）的问题

```
IoU_2D = |mask_A ∩ mask_B| / |mask_A ∪ mask_B|   （图像像素级）
```

**问题**：同一物体从不同角度拍摄时，2D mask可能完全不重叠，IoU_2D = 0，关联失败！

#### 3.6.2 本文方法（3D点集IoU）

直接在3D点索引空间计算重叠：

```
设 A = 当前帧检测的点集
   B = 已知实例的点集

IoU_3D = |A ∩ B| / |A ∪ B|
```

#### 3.6.3 双向最大匹配 ✅ 已完成

构建 K×M 的IoU矩阵（K个检测，M个已知实例），采用双向一致性匹配：
- 列方向：每个实例找IoU最大的检测
- 行方向：每个检测找IoU最大的实例
- 双向一致才确认匹配

---

### 3.7 Step 4：实例更新与贝叶斯语义融合

#### 3.7.1 匹配到已有实例 ✅ 已完成

- 合并点集：将新检测的点加入实例
- 更新语义标签：累加置信度

#### 3.7.2 创建新实例 ✅ 已完成

若未匹配到任何已有实例，创建新实例。

#### 3.7.3 【P0 待完善】贝叶斯语义融合

> **状态**：🔲 待完善 | **优先级**：P0 | **难度**：⭐⭐☆☆☆
>
> 代码框架已完成，仅需创建似然矩阵文件。

**问题**：简单累加的问题——"floor"、"carpet"、"mat"可能指同一东西。

**贝叶斯方法原理**：

通过似然矩阵 P(measurement | class) 将开放词汇映射到预定义类别：

```
预定义类别（11类）：[floor, ceiling, wall, pillar, door, window, stair, chair, table, sofa, other]

贝叶斯更新：
  P(class | 观测1, 观测2, ...) ∝ P(class) × ∏ P(观测i | class)
```

**待完成**：创建似然矩阵文件 `bayesian_model.txt`

## 四、阶段三：自适应点云投影与CAD线段提取

### 4.1 目标

从结构点云 (removed.pcd) 中提取墙体的2D平面图。

### 4.2 Step 1：地板分离与坐标对齐 ✅ 已完成

- RANSAC 平面拟合：检测地板平面
- 分离地板点与非地板点（墙体等）
- 坐标对齐：将地板法线旋转到Z轴，墙体主方向旋转到X轴

### 4.3 Step 2：自适应高度检测 ✅ 已完成（辅助创新）

**问题**：需要指定水平切片的高度范围，但不同建筑高度完全不同。

**方法**：对Z轴建立直方图，自动检测地板和天花板峰值位置：
- 地板：Z直方图低位峰值
- 天花板：Z直方图高位峰值
- 切片范围：自动计算

### 4.4 Step 3：多层切片投票 ✅ 已完成

将高度范围等分为多层切片，每层独立投影到2D栅格。

投票规则：某像素被 ≥ minVotes 层命中才保留。

### 4.5 Step 4：栅格化 ✅ 已完成

设定栅格分辨率（如每像素代表2.5cm），将点云投影到2D栅格图像。

### 4.6 Step 5：线段检测与合并 ✅ 已完成

```
投票后的二值图
    │
    ├─ 形态学闭操作
    ├─ 高斯平滑 + 二值化
    ▼
骨架化 (Zhang-Suen thinning)
    │
    ▼
HoughLinesP 直线检测
    │
    ▼
共线碎片合并（无Manhattan约束）
```

### 4.7 像素坐标 → 真实尺度 ✅ 已完成

线段像素坐标乘以栅格分辨率，转换为真实米制坐标。

### 4.8 输出格式 ✅ 已完成

| 文件 | 格式 | 用途 |
|------|------|------|
| v3_step5_final_scaled.png | PNG | 带比例尺的可视化图 |
| floorplan.dxf | DXF R12 | AutoCAD/Revit可直接打开 |
| floorplan.svg | SVG | 矢量图，含比例尺 |
